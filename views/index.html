API para administrar platos y categorías. Consultá el menú, buscá por nombre y filtrá por categoría o precio. Las respuestas se devuelven en JSON.

URL base http://localhost:3001/api

Endpoints

Platos y categorías

Abrí los enlaces GET o copiá las URLs a Thunder Client. Para POST y PUT, enviá un cuerpo JSON. Reemplazá :id por un identificador real.

Métodos, URLs y descripción de los endpoints de Arte-Sano
Método URL Descripción
Platos
GET http://localhost:3001/api/dishes Lista todos los platos con su categoría.
GET http://localhost:3001/api/dishes/6aab8a4055c9e41c57e478ee Obtiene un plato por ID. El enlace consulta los Ravioles de ejemplo.
GET http://localhost:3001/api/dishes?name=pizza Busca por nombre, sin distinguir mayúsculas y minúsculas.
GET http://localhost:3001/api/dishes?category=6aab87590770a223e2d18630 Filtra por categoría. El ejemplo utiliza Pastas.
GET http://localhost:3001/api/dishes?minPrice=10000&maxPrice=15000 Filtra por rango de precios, incluyendo ambos límites.
GET http://localhost:3001/api/dishes?name=ravi&minPrice=10000&maxPrice=15000 Combina búsqueda por nombre y precio.
POST http://localhost:3001/api/dishes Crea un plato con nombre, descripción, precio y categoría. Disponibilidad opcional. Requiere JWT de administrador. Sin token válido devuelve 401; con usuario común, 403.
PUT http://localhost:3001/api/dishes/:id Actualiza nombre, descripción, precio, disponibilidad y categoría. Exige los cinco campos. Requiere JWT de administrador. Sin token válido devuelve 401; con usuario común, 403.
DELETE http://localhost:3001/api/dishes/:id Elimina un plato por ID. No requiere cuerpo. Requiere JWT de administrador. Sin token válido devuelve 401; con usuario común, 403.
Categorías
GET http://localhost:3001/api/categories Lista todas las categorías.
GET http://localhost:3001/api/categories/6aab87590770a223e2d18630 Obtiene una categoría por ID. El ejemplo consulta Pastas.
POST http://localhost:3001/api/categories Requiere JWT de administrador. Sin token válido devuelve 401; con usuario común, 403. Si se crea, devuelve 201; si el nombre ya existe, 409.
PUT http://localhost:3001/api/categories/:id Requiere JWT de administrador. Actualiza nombre y descripción. Sin token válido devuelve 401; con usuario común, 403. Si el nombre pertenece a otra categoría, devuelve 409.
DELETE http://localhost:3001/api/categories/:id Requiere JWT de administrador. Sin token válido devuelve 401; con usuario común, 403. Si la categoría tiene platos asociados, devuelve 400 y no la elimina.
Autenticación
POST /api/auth/register Registra un usuario común. Devuelve 201 sin incluir la contraseña.
POST /api/auth/login Inicia sesión. Devuelve un JWT válido por una hora.
GET /api/auth/me Devuelve ID, nombre, email y la ruta de la foto si existe. Requiere Authorization: Bearer TU_TOKEN.
POST /api/auth/profileimage Actualiza tu foto de perfil. Requiere JWT y una imagen JPEG, PNG o WebP de hasta 2 MiB.

Los identificadores de ejemplo corresponden a la base de desarrollo. Si eliminás esos registros, utilizá los IDs devueltos por los listados.
